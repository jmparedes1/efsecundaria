# PREMIR · versión gratuita mejorada

Empieza por [GUIA_PASO_A_PASO.md](GUIA_PASO_A_PASO.md).

Archivos principales:

- `index.html`: portada.
- `app.css`: diseño.
- `app.js`: buscador, filtros, visor, acceso y favoritos.
- `admin.html` y `admin.js`: panel de administración.
- `resources.json`: catálogo inicial.
- `firebase-config.js`: activa el modo local o Firebase.
- `firestore.rules`: reglas que se copian en Firebase.

La configuración inicial usa `mode: "local"`, por lo que la web funciona en GitHub Pages sin crear Firebase.
